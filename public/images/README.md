# Recursos fotográficos de la Home

La Home utiliza rutas locales para fotografías reales autorizadas.

Añade los siguientes archivos:

- hero-padel.jpg
  Fotografía panorámica para el hero principal.

- event-padel.jpg
  Fotografía de la pista o sede de la próxima prueba.

- ranking-padel.jpg
  Fotografía horizontal para el fondo del ranking.

- sagunto-panorama.jpg
  Fotografía de Sagunto autorizada para uso web.

No se han incluido imágenes de stock ni imágenes generadas por IA.

Mientras falten las fotografías, los bloques mostrarán fondos de color de respaldo.
