# Sagunto Padel Cup

Plataforma web del circuito Sagunto Padel Cup para consultar torneos, calendario,
clasificaciones, jugadores y noticias, además de gestionar cuentas, inscripciones
y operar la competición desde el panel administrativo.

## Requisitos

- Node.js compatible con la versión validada por el proyecto.
- npm.
- Un proyecto Supabase con el esquema y las políticas RLS esperadas por
  `src/types/database.ts`.
